{% if include.kind == 'caratheodory' %}

역사적 문제의 n = 1 계수 곡선 위에 수치 가중치를 선택한 보충 예제이다. A = (1, 0), B = (0, 1), C = (−1, 0), D = (0, −1)는 고정된다. 질량은 출판된 관측 자료가 아닌 학습용 선택이다. 모든 수정은 가상이며 물리적 단위는 없다.

{% elsif include.kind == 'vector-error' or include.kind == 'matrix-error' %}

{{ include.source_label | escape }}(1999)에 발표된 예시 자료의 기준값이다. 기준값은 고정되며 근사값 수정은 가상 실험이다. 원문은 물리적 단위를 지정하지 않는다. 출력은 현대적으로 다시 계산하며 표시값은 반올림한다.

{% elsif include.kind == 'vector-norm' or include.kind == 'matrix-norm' %}

보충 학습을 위해 직접 만든 예제이다. 기본값은 역사적 관측 자료가 아니며 수정은 가상 실험이다.

{% elsif include.kind == 'convexity-mixture' %}

{{ include.source_label | escape }}에 발표된 고정 예시 자료이다. 용량은 (3, 3, 1) 기계·일, 부품 I/II의 생산율은 (10/20, 20/30, 30/80)이다. 배분 S = (2, 9/5, 8/11)과 O = (8/3, 3, 0)은 여기서 정확히 다시 유도했다. 모형은 시간 분할, 완전 가동, 짝이 맞는 부품, 준비 비용 없음을 가정한다. 초기 중점과 가중치 변경은 모두 역사적 관측이 아닌 가상의 혼합이다.

{% elsif include.kind == 'convexity-chord' %}

{% elsif include.kind == 'duality' %}

{{ include.source_label | escape }}에 발표된 예시 자료의 기준값이다. 용량은 (3, 3, 1) 기계·일, 부품 I/II의 생산율은 (10/20, 20/30, 30/80)이며 자료는 고정된다. 현대적 모형은 시간 분할, 완전 가동, 부품 수의 정확한 일치, 준비 비용 없음을 가정한다. 초기 가중치 2/3은 여기서 유도한 증명서이며 변경은 가상의 증명서 실험이다.

{% elsif include.kind == 'farkas' %}

{{ include.source_label | escape }}에 발표된 고정 예시 자료이다. 용량은 (3, 3, 1) 기계·일, 부품 I/II의 생산율은 (10/20, 20/30, 30/80)이다. 목표는 가상이며 기본값 90은 발표된 역사적 목표가 아니다. 현대적 모형은 시간 분할, 완전 가동, 잉여 부품 허용, 준비 비용 없음을 가정한다.

{% elsif include.kind == 'kantorovich' %}

발표된 예시 자료의 기준값이다. 밀링 3, 터릿선반 3, 자동선반 1 기계·일과 {{ include.source_label | escape }}의 고정 부품 I/II 생산율을 사용한다. 배분과 교환은 시간 분할, 완전 가동, 부품 수의 정확한 일치, 준비 시간 없음을 가정하여 현대적으로 다시 유도했다. 분수 출력은 일일 생산율이다. 용량 변경은 가상 실험이다.

{% elsif include.kind == 'linear-programming' %}
